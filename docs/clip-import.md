# CLIP STUDIO アニメーションの読み込み

保存済みの`.clip`をPMAnへドラッグ＆ドロップするか、CLIP STUDIOアニメーションの
読み込みメニューで選択します。PMAnのウィンドウだけでなく、起動前のアプリアイコンへ
ドロップしても読み込めます（`.clip`の関連付けはクリスタのまま変わりません）。
現在のドキュメントと置き換える前に解析し、失敗した場合は現在のドキュメントを
維持します。元ファイルへの書き込みは行いません。
読み込んだ線画は、そのまま色塗り前の初期状態として保持します（尋ねません）。
自動塗りの精度が上がり、キャンバス下のボタンで見比べられます。

## 自動塗りの初期状態として読み込む

**自動塗り › CLIPの線画を初期状態として読み込む…**から、塗り済みのプロジェクトへ
元の線画を追加できます。アニメーションフォルダー名とセル番号で対応付け、
現在の絵・タイムライン・FPSは維持します。セル番号は通常のCLIP読み込みと同じ規則で
割り当てます。タイムライン上の配置位置は対応付けに使用しません。

一致するセルと連番アーカイブ内の未配置セルへ初期状態を設定し、一致しないセルは維持します。
線画と現在のセルは同じ画像サイズが必要です。全体を1回のUndoで戻せます。

## 実装と更新

`native/src/clip.rs`が[clipfile-rs](https://github.com/Aodaruma/clipfile-rs)の
公開APIをPyO3で公開します。`clipfile`はバージョン上限を設けず、CI・配布ビルドのたびに
`cargo update --manifest-path native/Cargo.toml -p clipfile`でcrates.ioの最新公開版へ
更新します。解決結果はビルド時の`native/Cargo.lock`に記録されます。
APIや依存関係の非互換があればビルド・テストで停止するため、PMAn側の追従が必要です。
コンテナ検証、読み取り専用SQLite、レイヤーツリー、
タイムライン、ミキサーカーブ、ラスタータイルの展開は上流ライブラリが担当します。

`paintmaskanimator/clip_animation.py`は、画像のQt変換、セル内レイヤーの合成、
PMAnのセル番号・露出・連番アーカイブへの変換を担当します。配置座標とレイヤー色など、
上流の型にない数値列だけは、上流が提供する読み取り専用DB接続からRust側で取得します。
独自のコンテナ・ミキサー・タイルパーサーやPythonフォールバックは持ちません。

ソースから最新を使う場合は、次の順に拡張を更新してください。

```sh
cargo update --manifest-path native/Cargo.toml -p clipfile
pip install ./native
```

`pip install ./native`だけでは既存のlockファイルの版を使います。
インストール済みのアプリへ上流の更新が直接反映されることはなく、配布版ではPMAnの更新が必要です。
拡張が未導入・旧版の場合は読み込み時に更新方法を表示します。
Rust拡張はCLIP読み込みを含めアプリ全体で必須です。`PMA_NO_NATIVE`による無効化は廃止しました。

## 対応範囲

- 選択されたタイムラインのFPS・開始／終了フレーム・セル指定を読み込みます。
- セルがフォルダーの場合は子レイヤーを合成します。可視状態、不透明度、合成モード、
  クリッピング、レイヤーマスク、配置座標を反映します。
- 未配置のセルも連番アーカイブ用に保持します。負のフレームのキーはシートへ持ち込みません。
- カラー、8bitグレー、8bitアルファ、グレー＋アルファの保存画像を使用します。
- 現在の依存版では1bit（モノクロ／ビットパック）や高ビット深度の画像は未対応です。
  旧Python実装の1bit展開は削除しており、これらの画像は読み込みエラーになります。
  クリスタ側で対象レイヤーをカラーまたは8bitグレーへ変換して保存してください。
- クリスタの全機能の再現ではありません。ベクター等は保存された表示画像を利用し、
  3Dや特殊な描画機能、カメラ・エフェクト等の完全再現は保証しません。
- クリスタの画面からレイヤーを直接ドラッグする操作や、`.cmc`の読み込みは対象外です。

依存更新時は拡張を再ビルドし、`python -m pytest tests/test_clip_animation.py`を実行します。
テストは上流の構造検証を通るコンテナとSQLiteを生成し、画像、マスク、合成、露出、
負のキー、未配置セル、読み込み失敗時のドキュメント維持を確認します。
