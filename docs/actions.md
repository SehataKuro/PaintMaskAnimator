# Python アクション

アクションパネルは、Python スクリプトからカスタムボタンを追加できる拡張の仕組みです。
組み込みアクションもユーザー定義アクションも、すべて同じ `*.py` スクリプトとして
アクションフォルダに置かれ、アプリ内エディタで編集できます。

> **セキュリティ:** アクションスクリプトは通常の Python コードであり、あなたの
> 権限でそのまま実行されます。信頼できる提供元のスクリプトのみをインストール・
> 実行してください。

## アクションフォルダ

各スクリプトはユーザー設定フォルダ内の `actions/` ディレクトリに置かれます
（`config.config_dir() / "actions"`）。このフォルダは初回起動時に自動生成され、
組み込みアクションのスクリプトが書き出されます。

フォルダ直下の `*.py` ファイルが読み込み対象です。ファイル名が `_` で始まるものは
無視されるため、共有モジュールやヘルパーは `_utils.py` のように命名できます。

## スクリプトの編集（アプリ内エディタ）

アクションパネル右下のハンバーガーメニュー **☰ → スクリプトを編集** から、
アプリ内の Python エディタが開きます。エディタには次の機能があります。

- 左ペイン: アクションフォルダ内スクリプトの一覧
- 右ペイン: 行番号ガター・現在行ハイライト・シンタックスハイライト付きエディタ
- **新規**: テンプレート付きの新しいスクリプトを作成
- **削除**: 選択中のスクリプトを削除（組み込みも削除可能）
- **保存**: 現在のスクリプトを保存
- **保存して再読み込み**: 保存後にすべてのアクションを再読み込みし、ボタンへ即反映
- **閉じる**: エディタを閉じる（未保存の変更があれば確認）

編集内容を反映するには **保存して再読み込み** を使ってください。単に **保存** した
だけではボタン一覧は更新されません。

## スクリプトの書き方

各スクリプトは `register_actions(panel, window)` 関数を公開する必要があります。
アプリはこの関数を呼び、その中で `panel.add_action(...)` を呼んでボタンを追加します。

```python
def register_actions(panel, window):
    panel.add_action(
        "my.unique.action",              # 一意なアクション ID
        "My Action",                     # ボタンのラベル
        lambda: window.status_bar.showMessage("Done", 3000),
        tooltip="Optional help text",    # 任意
    )
```

- `window` はメインウィンドウです。`window.status_bar`（下部ステータスバー）や
  各種メソッドを通してアプリを操作できます。
- 1 つのスクリプトから複数のアクションを登録できます。

## `panel.add_action` リファレンス

```python
panel.add_action(action_id, label, callback, *, tooltip="", checkable=False)
```

| 引数 | 説明 |
| --- | --- |
| `action_id` | 一意な文字列 ID。空文字や既存 ID と重複すると `ValueError`。 |
| `label` | ボタンに表示する文字列。 |
| `callback` | クリック時に呼ばれる呼び出し可能オブジェクト。 |
| `tooltip` | 任意。ボタンのツールチップ。 |
| `checkable` | `True` でトグルボタンになる（下記参照）。 |

戻り値は生成された `QPushButton` です。

## チェック可能なアクション

`checkable=True` を指定すると、ボタンはトグル状態を持ちます。このときコールバックは
チェック状態（`bool`）を引数として受け取ります。

```python
def register_actions(panel, window):
    panel.add_action(
        "my.toggle",
        "Toggle Something",
        lambda checked: window.set_something(checked),
        checkable=True,
    )
```

通常（非チェック）ボタンのコールバックは引数なしで呼ばれます。

## 組み込みアクション

組み込みアクションも編集可能なスクリプトとして提供され、初回起動時に
アクションフォルダへ書き出されます。ユーザーが編集・削除した内容は
マーカーファイル（`.builtin_seeded.json`）によって記録され、再生成で
上書きされることはありません。

| ファイル | ラベル | 内容 |
| --- | --- | --- |
| `builtin_silhouette.py` | 背景以外を黒シルエット表示 | チェック可能。背景以外を黒シルエット表示（`window.a_silhouette`）。 |
| `builtin_same_image_replacement.py` | 同一画像から色置換 | 同じタイムライン位置の上レイヤーと画素配置を比較し、一致した色対応を実画像へ適用。 |
| `builtin_main_line_repaint.py` | MainLineRepaint | メイン色・サブ色を線レイヤーへ分離し、抜けた面を周囲の最多色で埋める。 |

組み込みスクリプトはユーザー定義アクションのお手本にもなります。エディタで
開いて書き方を確認できます。

## 読み込みの挙動とエラー処理

- 読み込み時、組み込みスクリプトの書き出し（未シード分のみ）→ ユーザー定義
  アクションの再登録の順で処理されます。
- スクリプトはファイル名順（`sorted`）に読み込まれます。
- 個々のスクリプトは分離して読み込まれ、あるスクリプトが失敗しても他は登録
  されます。失敗したファイルはまとめて警告ダイアログに表示されます。
- アクションボタンのコールバックが例外を送出した場合、アプリはクラッシュせず、
  エラー内容とトレースバックをダイアログで表示します。

## トラブルシューティング

- **ボタンが出ない**: `register_actions(panel, window)` が定義されているか、
  ファイル名が `_` で始まっていないかを確認してください。編集後は
  **保存して再読み込み** を実行します。
- **「読み込みエラー」ダイアログ**: 該当ファイルの構文エラーや、
  `register_actions` の欠如が原因です。メッセージのファイル名を確認してください。
- **「アクション ID が既に存在します」**: 別スクリプトと `action_id` が重複して
  います。一意な ID（例: `yourname.category.action`）を付けてください。

サンプルは [`examples/actions/hello_status.py`](../examples/actions/hello_status.py)
を参照してください。
