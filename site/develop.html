開発者向け

ソースから動かす人、コードを読む人、直したい人のための入口。

コードの状態を見る

どちらも main への push ごとに CI が更新します。プルリクエストの内容はまだ反映されていないので、 その場合は Actions のラン画面のサマリに出る数値を見てください。

  • カバレッジレポート

    テストがどの行を通ったかを、ファイル単位・行単位で確認できます。

  • 機能検証マップ

    どの機能にどのテストが付いているかの一覧。抜けているところが分かります。

  • CI の実行結果

    ruff・pyright・テスト・カバレッジのしきい値をまとめて確認しています。

構造をつかむ

paintmaskanimator/ は 125 モジュール・約 61,000 行あります。全体の地図を作るには Understand-Anything が使えます。Tree-sitter でソースを解析して import や定義の関係を取り出し、そこに要約・レイヤー・ドメインを重ねた 対話的なナレッジグラフを作るツールです（MIT ライセンス）。

  • 構造グラフ

    レイヤー表示・ドメイン表示・ガイドツアー・検索つきのダッシュボード。何も入れずにブラウザで見られます。

グラフはリポジトリの .ua/ に入っていて、main に push されるとこのサイトの ダッシュボードも置き換わります。見るだけなら、生成し直す必要はありません。

手元で開きたい場合は、リポジトリに入っているグラフをそのまま読み取り専用ビューアで開けます。

npx understand-anything-viewer

グラフを更新する

構造が大きく変わったら、誰か 1 人が Claude Code で作り直してコミットします。 準備が済んでいれば、main で次を実行して .ua/ をコミットするだけです。 前回のグラフとの差分だけを解析し直します。 

/understand

初めての環境での準備、全部作り直すとき、プラグインを更新したときの手順は docs/knowledge-graph.md にまとめています。

ソースから実行する

Python 3.10 以上が必要です。開発時の起動には Rust 拡張が必須なので、Rust のツールチェーンも用意してください。

pip install -e ".[dev,full]"
pip install ./native
python PaintMaskAnimator.py

提出前のチェックは次の 1 本でまとめて走ります。

python scripts/preflight.py

読むもの

  • CONTRIBUTING.md

    開発環境の準備、提出前のチェック、翻訳、リリース手順。

    「なぜそうしないのか」を残したメモ。原画工程を対象にしない理由、セル番号を整数に限る理由など。

    プロジェクトファイル .pman の形式。

  • アクション API

    アクションパネルに Python でボタンを足すための register_actions の仕様と、組み込みアクションの一覧。

  • CLIP 読み込み

    .clip から読める範囲と読めない範囲。

  • 自動塗りの処理と計測

    任意の GPU 支援と、速度の測り方。
