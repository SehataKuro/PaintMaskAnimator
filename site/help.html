インストールとアップデートについて。

macOS で「開けません」と表示される

PaintMaskAnimator は Apple による公証（Notarization）を受けていないため、初回の起動時に macOS の Gatekeeper がブロックすることがあります。このサイトか GitHub の Releases から入手したものであることを確かめてから、次の手順で許可してください。一度許可すると、2 回目以降は通常どおり起動できます。

  1. DMG を開き、PaintMaskAnimator を「アプリケーション」フォルダへドラッグします。
  2. アプリを開くと警告が表示されるので、「完了」で閉じます。
  3. 「システム設定」›「プライバシーとセキュリティ」を開き、下の方にある「このまま開く」をクリックします。
  4. パスワードまたは Touch ID で確認し、もう一度「このまま開く」をクリックします。

Apple Silicon（M1 以降）専用です。Intel Mac では動作しません。

Windows で「PC が保護されました」と表示される

インストーラーにコード署名がないため、Microsoft Defender SmartScreen の警告が表示されることがあります。

  1. 警告画面の「詳細情報」をクリックします。
  2. アプリ名が PaintMaskAnimator-Setup-… であることを確認し、「実行」をクリックします。

アップデート

インストール済みのアプリは、起動時に新しいバージョンがあるかを確認し、あればお知らせします。

0.6.4 以前のバージョンは自動では更新されません。お手数ですが一度だけ ダウンロード から最新版をインストールし直してください。
