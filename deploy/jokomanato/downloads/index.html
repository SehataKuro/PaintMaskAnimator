macOS で「開けません」と表示されたとき

PaintMaskAnimator は Apple の公証（有料の開発者登録）を受けていないため、 初回だけ macOS が起動を止めます。アプリは Apple Silicon（M1 以降）専用で、 Intel Mac には対応していません。

  1. DMG を開き、PaintMaskAnimator を「アプリケーション」フォルダへドラッグします。
  2. アプリを開くと「開いていません」という警告が出るので、「完了」で閉じます。
  3. 「システム設定」›「プライバシーとセキュリティ」を開き、下の方にある 「"PaintMaskAnimator" は…ブロックされました」の横の「このまま開く」を押します。
  4. パスワードまたは Touch ID で確認し、もう一度「このまま開く」を押します。

2 回目以降は普通に起動できます。

ターミナルを使う場合

アプリをアプリケーションフォルダへ入れたあと、次のコマンドでも警告を解除できます。

xattr -dr com.apple.quarantine /Applications/PaintMaskAnimator.app
